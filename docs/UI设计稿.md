> 状态：阶段 05 已审核通过 v1.0（用户 2026-11-18 确认）。
> 适用：PRD v1.2 R1 重构对齐版。
> 设计来源：旧版 Mile Knowledge Base v2.7.0 的运行截图。截图是在沙箱里运行旧版最新构建 `out/`（2026-11-17 20:16）得到的，截图与清单在 [`design/baseline/`](../design/baseline/)。
> 原则：重写版的 UI、UX 与布局与旧版一致（PRD G2），本阶段不重新做视觉设计。截图是视觉定稿，本文件说明页面结构、入口与返回、状态覆盖，以及哪些地方截图表达不了。

## 1. 导航与页面层级

```text
应用窗口（单窗口，无边框，自绘 40px 标题栏）
├── 欢迎页            —— 没有可打开的知识库时
│   └── 新手引导（2 步）
└── 工作台            —— 打开知识库后
    ├── 左：侧栏（知识库树、搜索入口、底部：操作日志 / 导入技能 / 设置）
    ├── 中：对话区（永远展开）
    │   ├── 历史栏（可开合，200px）
    │   ├── 空状态 = 总览磁贴
    │   └── 输入框与运行参数条
    ├── 右：文档面板（可折叠为 40px 竖轨）
    │   ├── 搜索面板（Ctrl+P，顶部）
    │   ├── 标签栏 + 编辑器（阅读 / 源码 / 分栏）
    │   └── 反向链接、来源追踪等小节
    └── 覆盖层：设置页、技能导入向导、健康面板、会话信息浮层、操作日志面板
```

- 栏宽：侧栏默认 232（192–320），文档面板默认 560（320–800），中间对话列最小 480，栏间 8px 缝即拖拽条（PRD FR-SET）。
- 窗口变窄时先压缩文档面板，不压缩对话列。
- 覆盖层（设置、导入向导）位于标题栏下方，不是路由跳转；关闭后回到原工作台状态，栏宽、展开的目录、打开的标签都保持不变。

## 9. R2 技能浮层（新增，PRD 第 15 节 FR-SKM-PANEL）

> 状态：用户 2026-11-20 审核通过（含毛玻璃修订）。旧版没有这个界面，视觉稿是 HTML 原型 [`design/r2/skills-panel.html`](../design/r2/skills-panel.html)，直接引用工程的 `src/styles/tokens.css`；截图在 `design/r2/shots/`（9 个状态 × 浅 / 深，共 18 张，1440×900）。
> 用户决定（2026-11-20）：入口放在标题栏；侧栏底部原有的「导入技能」并入浮层的「安装」，不再保留两个入口；UI 稿用 HTML 原型加截图。

### 9.1 位置与层级

```text
标题栏：[图标 Mile Knowledge Base VAULT  库名 ......  [技能 2] [浅色|深色|系统] - □ x]
                                                     │
                    ┌────────────────────────────────▼┐  ← 右缘对齐按钮右缘
┌──────┐ ┌──────────│ 浮层 760×560                    │┐ ┌──────────┐
│ 侧栏 │ │ 对话列   │ 顶栏 / 主体（滚动）/ 底栏       ││ │ 文档面板 │
│      │ │          └─────────────────────────────────┘│ │          │
│      │ │ [输入框]                                   │ │          │
└──────┘ └────────────────────────────────────────────┘ └──────────┘
```

- 入口：标题栏里知识库名与主题切换之间的「技能」胶囊按钮。打开知识库与否、设置页是否打开，它都在。
- 角标：数量 = 知识库有更新的拷贝 + 失效链接，为 0 时不显示。角标只是提示，打开浮层不会清零。
- 浮层：从标题栏下方 6px 处展开，右缘对齐按钮右缘，宽 760、高 560。窗口太窄时宽度收缩，左缘不越过侧栏右缘；放不下 560 高时，高度收到距窗口底 8px。
- 浮层不是覆盖层：不遮挡标题栏，不盖侧栏，工作台照常可见，但浮层打开时其余区域不响应点击（点外面即关闭）。设置页打开时也可以弹出，层级在设置页之上。
- 关闭：Esc、点浮层外、右上角 ×、再次点「技能」按钮。关闭后焦点回到按钮。子视图（分发、收编、安装）里按 Esc，先回到上一级列表，再按一次才关闭。

### 9.2.1 真实实现截图（M4 T15，2026-11-20）

`design/r2/shots/` 的 18 张已换成真实实现的截图（9 个状态 × 浅 / 深，1440×900，来自 e2e 构建 + 假 HOME）。与原型逐张对照的差异按 DESIGN.md 11.4 允许的范围记录：
