## 1. 目标、范围与授权

目标：

1. 详情抽屉：知识库技能卡片可点，右侧抽屉显示头部、分发情况、来源与 `SKILL.md` 预览，底栏有分发 / 更新 / 在侧栏定位 / 在工作台编辑（UI 稿 12.2、DESIGN 14、技术设计 20.3）。
2. 安装弹窗：三种来源、候选、目标、结果都在一个居中弹窗里；进行中不能关闭（Q-UX-6）。
3. 分发弹窗：方式、目标格、覆盖确认（叠层）、结果都在弹窗里；完成后退出批量选择。
4. 导航整理：筛选框、两组可折叠（状态存 `layout`，Q-UX-3）、「管理目录」移到工具组头、「未检测到的工具」折叠、底部两行。
5. 验收：AC-UX-1–13 自动化；真窗口视觉对照；性能门禁（含 1.6.1 遗留的滚动测量问题，Q-M9-3）。

不做：工具技能的详情抽屉（Q-UX-1）；收编、更新、还原、管理目录改弹窗（Q-UX-2）；抽屉内编辑（Q-UX-4）；改变任何技能管理的规则、写入边界与外连；新增依赖；把材质推广到技能页以外。

授权边界：测试与 e2e 只用临时目录、假 HOME 与本地假 GitHub，不读写真实工具目录、真实知识库与真实应用数据，不访问真实 GitHub；Agent 权限不变（PRD 15.4）。

## 7. 协作、审查与执行方式

- 一次一个任务，汇报后停下；整份计划的批准不等于各任务放行。
- 不用子代理或并行会话执行编号任务；T09 的审查方式按 B-M9-03。
- 每个任务结束提交到本地（不推送）；推送只在 T10 列清单后由用户决定。
- 安装包安装（B-M9-01）执行前单独征得同意；安装前确认没有运行中的实例；冒烟前后核对真实 `settings.json`（只读比对）。
- 全量 e2e 必须带 `-tags=e2e` 的构建；正式包用不带标签的 `bun run build` 重新打，不要复用 e2e 产物。
- Vitest 需要 Node ≥ 22.19（本机 nvm 当前是 20.19.0，只在命令内临时用 22.23.4，不改全局）。
